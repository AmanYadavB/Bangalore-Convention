Public Dashboard

This dashboard shows totals and charts powered by a Google Sheet. To set it up: create a Google Form (or Formspree), connect responses to a Sheet, create charts and publish them (File → Publish to web). Paste the published chart URLs into public/config.json under DASHBOARD_EMBEDS.

Simple totals (from sheet)

If you publish a small totals chart or value, add its embed URL to config.json and it will appear above.

Admin

To add expenses or edit registrations, open the underlying Google Sheet directly (or use a separate admin Form that writes into the same sheet).
